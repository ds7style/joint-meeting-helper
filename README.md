# 합동회의 지정 도우미

합동회의 일정이 확정되면, 비상임심판관 풀(최대 36명) 중에서 약 10명을 **순위(1·2·3순위)대로 연락하고 참석·불참 회신을 모아 주는 웹 앱**입니다. 담당자가 개인 휴대폰 메시지로 한 분씩 연락하고 엑셀·메모에 옮겨 적던 일을 자동화하는 것이 목표입니다.

> 이 저장소는 교육·실습 과정의 결과물입니다. 실제 알림톡은 보내지 않는 **모의 발송**으로 만들었고, 예시 데이터는 모두 가상입니다. 공식 서비스가 아닙니다.

**배포 주소:** https://my-app-rho-ebon-14.vercel.app

## 무엇을 하나요

1. 담당자가 회의 날짜, 정원, 비상임심판관 명단과 순위를 입력합니다. (1순위 인원은 정원과 같아야 합니다.)
2. 저장하면 1순위 전원에게 **모의 발송**합니다. (실제 메시지는 가지 않고 "보냈다"는 기록만 남깁니다.)
3. 심판관은 받은 링크에서 **참석 / 불참** 버튼을 눌러 회신합니다. (로그인 없음, 한 번만 회신)
4. 불참이 나오면 정원이 찰 때까지 **다음 사람에게 자동 발송**합니다. (불참 1건마다 1명씩)
5. 담당자는 현황 화면에서 참석·불참·무회신 인원과 정원 대비 확정 인원을 봅니다.

## 주요 규칙

- 밤 9시~아침 8시에는 발송하지 않고 아침으로 미룹니다.
- 발송 후 **영업일 기준 24시간** 안에 회신이 없으면 현황 화면에 "미회신"으로 표시하고, 다음 발송 여부는 담당자가 정합니다.
- 정원이 차면 발송을 멈추고, 같은 줄(사람)에게 중복 발송하지 않습니다.
- 참석 → 불참은 앱에서 바꿀 수 없고, 담당자가 "불참 처리"(확인 창 포함)로 고칩니다.

## 기술

- Next.js 16 (App Router) · TypeScript · Tailwind CSS
- 배포: Vercel
- 데이터는 서버 메모리에 임시 보관합니다. (서버가 다시 시작되면 사라질 수 있습니다.)

## 실행해 보기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 비밀 키가 필요 없습니다.

```bash
npm run lint
npm run build
```

## 알아 둘 점

- 로그인이 없어서 주소를 아는 사람은 담당자 화면을 볼 수 있습니다. **가상 데이터만 입력하세요.** 실제 이름·번호를 넣으려면 먼저 접근 제한을 추가해야 합니다.
- 공휴일 목록은 예시 2개뿐입니다. (`lib/rules/time.ts`)
